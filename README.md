# Voice Controlled Knitting Counter App (WIP)
This project is a voice controlled row counter app for the raspberry Pi. It uses voice commands to keep track of your knitting so that you can continue to knit without having
to pick up your phone or mess with pen and paper. Allows you to keep track of the row count for multiple knitting projects.

Built with Python, uses Vosk for offline speech recognition and Kyutai pocket-tts for voice responses.



## Voice Commands 
- **"New project"** Create a new project
- **"Add row"** Increment the row count
- **"Frog row"** Decrement the row count
- **"Row count"** Hear the current row count
- **"List all projects"** Hear all saved projects
- **"Delete project"** Delete a project
- **"Current project"** Hear currently selected project
- **"Switch project"** Switch to another project
